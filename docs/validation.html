What these results establish

The extracted implementation reproduces the original method's actual files in the verified environment. Within each batch, the containers, compressed streams, and decoded audio differ. Running the same settings again reproduces the same variants.

Visual metrics were measured for all 66 pairs using a 4 fps sample reduced to 64×64 grayscale. Contact sheets of the master and u12 were inspected: the main frames, composition, and on-screen text are preserved. This was not a full-resolution review of every frame or an audio review of every MP4.

Verification limits

Instagram duplicate recognition, reach, and publication outcomes were not tested. MAE is neither a quality percentage nor a platform metric. Meaningful differences between captions require human review: a shared structure is allowed, but copied text and cosmetic variations are not.

Visual HTML rendering in a browser: not verified. The in-app browser blocked local file:// URLs. HTML structure and JavaScript checks are performed separately; no workaround was used to bypass the browser restriction.

Other source videos, FFmpeg builds, and operating systems require their own verification runs. Publication readiness also requires watching the complete files with sound.
